# Goal Tracker (RUBY)

A Ruby-based Goal Tracker for people who want to keep track of their goals, practice Ruby, or check out what basic Ruby code looks like.

## Cool Features

* **Goal Tracking**
* **Interactive Terminal Interface**
* **Goal Management**
* **Simple Ruby Logic**

## How to Run It

Ensure Ruby is installed
If it isn't visit the
[Official Ruby Installer Link](https://www.ruby-lang.org/en/downloads/)

To run the goal tracker directly in the terminal,

* Clone the repository
* Navigate to the repository in your terminal
* Run

  ```bash
  ruby goaltrack.rb
  ```
